# 🌍 Environmental Risk Analysis: Fossil Fuel vs. Electric Vehicles (LCA)

An advanced statistical and data visualization project built using **R** to analyze and compare the environmental lifecycle risks and carbon emissions between traditional fossil fuel vehicles (ICEVs) and Electric Vehicles (EVs).

## 🚀 Key Features
* **Lifecycle Assessment (LCA):** Evaluates emissions across manufacturing phases and annual operations.
* **Statistical Summary:** Computes descriptive statistics for risk indexes and emission levels.
* **Advanced Data Visualization:** Built with `ggplot2` to generate professional box plots and comparative bar charts.

## 🛠️ Built With
* **Language:** R (v4.x)
* **Libraries:** `tidyverse`, `ggplot2`

## 📊 Visualizations Included
1. **Environmental Risk Index Comparison:** Box plot analyzing overall risk distributions.
2. **Lifecycle Emissions Breakdown:** Grouped bar chart comparing manufacturing vs. operation emissions.
